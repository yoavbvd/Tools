# OSCP Report Tips

The exam is not passed until the report is accepted. A technically successful exam can still fail on a weak report.

## Requirements
- Document every step needed to **reproduce** each compromise, from scan to flag.
- Include a **screenshot of each flag** (`local.txt`, `proof.txt`) that also shows the command context and the target IP.
- Submit in the required format within the report window (about 24 hours after the exam).

## Structure
1. **High-level summary** — what you achieved, per target.
2. **Per-target walkthrough** — enumeration, exploitation, privilege escalation, with commands and screenshots.
3. **Appendix** — any supporting output.

## Practical tips
- Write the report **as you go**, not at the end. Paste commands and screenshots into your notes in real time.
- Use a template so formatting is consistent. OffSec provides a sample report template — start from it.
- Make commands copy-pasteable and exact. A reviewer must be able to follow them.
- Double-check that each required screenshot is present before you submit. A missing proof screenshot can lose the points.
